# Perks และด่าน

ไฟล์นี้สร้างจาก `src/core/perks.ts`, `src/core/items.ts` และ `src/core/stages.ts` ด้วย `npm run docs` ห้ามแก้ไขเอง

## Perk ทั้ง 50 แบบ

ราคาต่อเลเวล = ราคาฐานของ Tier x เลเวลที่ซื้อ (Tier 1-4: 20 / 35 / 55 / 80 เหรียญ)

ราคาในตารางคือราคาร้านแรก ทุกราคาขึ้น 20% ต่อด่านที่ผ่าน ปัดเป็นหลัก 5

## ไอเทมกดใช้

ไอเทมสุ่มออกปนกับ Perk ในการ์ด 3 ใบของร้านค้า แต่ละใบมีโอกาสเป็นไอเทม 20% (ที่เหลือเป็น Perk) ไอเทมเดียวกันไม่ออกซ้ำในการสุ่มครั้งเดียว และไม่ออกเมื่อถือครบ 3 ชิ้นแล้ว ไอเทมที่ถืออยู่ติดตัวข้ามด่าน กดปุ่มของไอเทมระหว่างต่อสู้เพื่อใช้ บัฟที่ใช้ซ้ำขณะยังทำงานอยู่จะต่อเวลาเพิ่ม บัฟหมดเมื่อจบด่าน
